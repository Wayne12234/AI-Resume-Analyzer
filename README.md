# AI-Resume-Analyzer
AI-powered Resume Analyzer built with Python, Gemini API, and PyPDF. The application extracts text directly from PDF resumes, analyzes candidate profiles using AI, identifies strengths and missing skills, and provides improvement suggestions along with resume evaluation feedback through a CLI-based workflow.
AI Resume Analyzer

AI Resume Analyzer is a Python-based CLI application that uses the Gemini API to analyze resumes automatically. The project reads resume data directly from PDF files using PyPDF, extracts textual content, and sends it to Google Gemini for intelligent evaluation.

The application provides:

resume analysis
skill evaluation
strengths identification
missing skill detection
improvement suggestions

This project demonstrates:

Python programming
PDF text extraction
API integration
AI prompt handling
CLI application development
real-world automation workflows

The system follows a simple workflow:

User places a PDF resume inside the project folder
Python extracts text from the PDF
Extracted content is sent to Gemini AI
Gemini generates resume feedback and evaluation
Results are displayed directly in the terminal
